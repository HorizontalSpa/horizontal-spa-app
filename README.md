# Telegram Mini App для сети массажных студий Horizontal Spa

Мини-приложение для Telegram: онлайн-запись на процедуры, личный кабинет с историей визитов и бонусами, программа лояльности, баннеры с акциями.

## Функциональность (текущая версия)

- Запись на процедуру онлайн (услуга, мастер, дата, время)
- Личный кабинет: баланс бонусов, число визитов, история записей
- Бонусы за визит, за отзыв и за каждые 10 визитов (начисляются автоматически)
- Отзыв/оценка визита
- Приглашение друга по номеру телефона
- Баннеры с акциями на главном экране
- FAQ, рекомендации по подготовке/уходу (эндпоинты готовы, экран пока не подключён)

Не реализовано в этой версии (см. раздел «Дальше»): витрина товаров с оплатой, дашборд для администратора, мониторинг свободных окон, пуш-уведомления, синхронизация с ЮKassa/др. платёжным провайдером.

## Технический стек

- Бэкенд: Node.js + Express + PostgreSQL (модуль `pg`), с резервным хранилищем в памяти, если БД недоступна
- Фронтенд: React + Vite (раньше был Create React App — read `CHANGELOG_2026-07-12.md`)
- Интеграция с Telegram Bot API и Telegram WebApp SDK

## Установка и запуск (локально)

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN и данные БД
npm run dev:server     # бэкенд на порту 3000 (или PORT из .env)
npm run dev             # фронтенд на Vite dev-сервере (порт 5173, проксирует /api на 3000)
```

Продакшен-сборка:
```bash
npm run build   # соберёт фронтенд в dist/
npm start        # поднимет server-render.js: API + БД + отдача dist/
```

## Размещение на Render.com

Настройки Render менять не нужно — `server-render.js` остаётся точкой входа, но теперь он использует общий `server.js` с API и БД внутри.

1. Web Service, Runtime: Node
2. Build Command: `npm install && npm run build`
3. Start Command: `node server-render.js`
4. Переменные окружения:
   - `NODE_ENV=production`
   - `BOT_TOKEN` — новый токен из @BotFather
   - `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` — данные вашей PostgreSQL на Render
5. После деплоя настройте Menu Button в @BotFather на URL вашего сервиса.

## Структура проекта

- `src/` — фронтенд (React + Vite): `App.js`, `components/`, `hooks/`, `api/client.js`
- `index.html`, `vite.config.js` — конфигурация сборки фронтенда
- `routes/api.js` — REST API
- `db.js` — работа с PostgreSQL (+ резервное хранилище в памяти) и правила начисления бонусов
- `bot.js` — отправка Telegram-уведомлений и проверка подписи Telegram initData
- `server.js` — единый Express-сервер (API + отдача собранного фронтенда)
- `server-render.js` — точка входа для Render (просто подключает `server.js`)
- `config.js` — конфигурация из переменных окружения
- `initdb.js` — разовый скрипт создания БД и сидовых данных (товары, FAQ)
- `legacy-vanilla-app/` — более ранняя версия фронтенда на чистом JS (не используется, оставлена для справки)
